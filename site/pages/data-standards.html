Standards and mappings

The data classes, their values and the sensitivity flags point to terms in published vocabularies and regulations, so that other systems can read RDDC data without an RDDC-specific mapping.

Why map at all

An RDDC class name such as rddc:SequenceReadsFile, or a value such as wgs, means something only to RDDC tools. Each mapping links it to a term that a repository, a catalogue or an analysis tool already knows. Mappings are documentation and metadata for consumers: a sidecar never contains them, and validation does not depend on them.

The model distinguishes how close a mapping is. A value's meaning is a term that means exactly the same thing. Where no term matches exactly, a close mapping is a term that means nearly the same thing, and a broader mapping is a term that covers more. A value with neither has no suitable term, such as targeted gene panel sequencing, which OBI does not define.

The vocabularies

EDAM
An ontology of data types and formats in bioinformatics (EDAM 1.25). Data classes map to EDAM data_ terms, such as sequence reads, sequence alignment and variant calls, as close or broader mappings. Classes with no fitting EDAM data term have none.
OBI
The Ontology for Biomedical Investigations (release 2026-07-27). Its assay terms are the meanings of the genomics assays, and of the imaging and sensing techniques OBI defines.
NCIT
The NCI Thesaurus (26.02d). Used for imaging and sensing techniques OBI has no term for, such as X-ray radiography, ultrasound and accelerometry.
SNOMED CT
The clinical terminology. Used where neither OBI nor NCIT has a term, such as clinical photography and continuous glucose monitoring.
W3C DPV
The Data Privacy Vocabulary's personal data extension (pd:, DPV 2.3). The sensitivity flags map to its categories of personal data, such as pd:PostalCode and pd:Biometric, and genomic data is pd:Genetic.
Croissant RAI
Croissant's Responsible AI extension. Its rai:dataCollectionType is the collection type annotation on data classes, so a release can copy it into the dataset's Croissant metadata.
schema.org and Croissant
Data file fields reuse their terms where one exists: measurementTechnique is schema.org's, and samplingRate is Croissant's. Their colour in code samples shows which vocabulary a key comes from.

Sensitivity flags and HIPAA Safe Harbor

The sensitivity flags follow the HIPAA Safe Harbor method of de-identification (45 CFR 164.514(b)(2)). Safe Harbor lists 18 kinds of identifier, (A) to (R). A batch confirms with directIdentifiersRemoved that the ones the flags do not cover were removed before upload. The flags declare the rest, which the RDDC accepts at deposit and handles itself: dates, postal codes and biometric identifiers. Free text is not an identifier itself, but can contain any of them.

How the batch and file values combine is described under Sensitivity in the sidecar concepts. Two kinds of data are identifying whatever the flags say: see Files that identify a person.
