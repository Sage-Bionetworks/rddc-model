Genomics

Sequencing reads, alignments, variant calls and their indexes. Every genomics file states how it was sequenced, and genomic data always identifies a person.

Assay and platform

Analysis requires two fields on every reads, alignment and variant file:

  • measurementTechnique: the sequencing assay, such as whole genome or exome sequencing. Values map to OBI assay terms.
  • sequencingPlatform: the sequencing technology, based on the INSDC platform types. It distinguishes short and long reads, which require different processing.

Optionally, set platform to the instrument model, such as Illumina NovaSeq X.

Assays

Sequencing platforms

Reads

A SequenceReadsFile holds reads, such as FASTQ or an unaligned BAM. Paired-end files reference each other through pairedWith.

Alignments and variant calls

Alignments (BAM, CRAM) and variant calls (VCF, BCF) specify their coordinate assembly in referenceGenome. UCSC build names map to the matching GRC assembly: hg19 is GRCh37 and hg38 is GRCh38.

A variant file can reference its source alignment through wasDerivedFrom.

Indexes

An IndexFile, such as .bai, .crai or .tbi, points to the file it indexes with indexOf. Indexes are binary.

Media types

FASTQ, BAM, CRAM, VCF and their indexes have no registered IANA media types. Genomics files use text/plain for the text formats and application/octet-stream for the binary ones, and the class says which format it is. BAM, CRAM and BCF compress internally, so they leave compression unset; gzipped or BGZF-compressed FASTQ and VCF set compression: gzip.

Sensitivity

Genome sequences, alignments and variant calls are identifying: they can identify a person on their own, and W3C DPV classes them as genetic data (pd:Genetic). Removing direct identifiers does not make them de-identified, regardless of sensitivity flags. Index files hold no sequence and are not identifying.
