Genomics

Sequencing reads, alignments, variant calls and their indexes. Every genomics file states how it was sequenced, and genomic data always identifies a person.

Assay and platform

Downstream analysis depends on how the data was produced, so every reads, alignment and variant file states two things:

  • measurementTechnique: the sequencing assay, such as whole genome or exome sequencing. Values map to OBI assay terms.
  • sequencingPlatform: the sequencing technology, based on the INSDC platform types. It tells short reads from long reads, which need different processing.

The instrument model, such as Illumina NovaSeq X, is optional and goes in platform.

Assays

Sequencing platforms

Reads

A SequenceReadsFile holds reads, such as FASTQ or an unaligned BAM. The two files of a paired-end run point to each other with pairedWith.

Alignments and variant calls

Alignments (BAM, CRAM) and variant calls (VCF, BCF) give the reference assembly their coordinates refer to in referenceGenome. UCSC build names map to the matching GRC assembly: hg19 is GRCh37 and hg38 is GRCh38.

A variant file can point to the alignment it was called from with wasDerivedFrom.

Indexes

An IndexFile, such as .bai, .crai or .tbi, points to the file it indexes with indexOf. Indexes are binary.

Media types

FASTQ, BAM, CRAM, VCF and their indexes have no registered IANA media types. Genomics files use text/plain for the text formats and application/octet-stream for the binary ones, and the class says which format it is. BAM, CRAM and BCF compress internally, so they leave compression unset; gzipped or BGZF-compressed FASTQ and VCF set compression: gzip.

Sensitivity

Genome sequences, alignments and variant calls are identifying: they can identify a person on their own, and W3C DPV classes them as genetic data (pd:Genetic). Removing direct identifiers does not make them de-identified, whatever the sensitivity flags say. Index files hold no sequence and are not identifying.

In a sidecar

Genomics files are grouped in a FileCollection file set. The genomics recipe is a complete whole-genome deposit: paired FASTQ reads, a CRAM alignment with its index, and a VCF.
