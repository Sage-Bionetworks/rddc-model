Genomics

Sequencing reads, alignments, variant calls, expression quantifications and their indexes. Reads and alignments name their format; variant calls name whether they hold germline variants, which identify a person.

Classes and formats

FASTQ, BAM, CRAM, VCF and BCF have no registered IANA media type: encodingFormat is text/plain for the text formats and application/octet-stream for the binary ones. Where the pipelines differ by format and the media type cannot tell the formats apart, the format is the class: reads are a FastqFile or an UnalignedBamFile, alignments a BamFile or a CramFile, each mapped to its EDAM format term. Variant calls are classed by what they contain, germline or somatic variants, and the media type and compression say whether a file is a VCF, a BCF or a MAF. Two abstract classes group the format classes, SequenceReadsFile and AlignmentFile, and VariantFile groups the variant classes. A file always names a concrete class.

Assay and platform

Analysis requires two fields on every genomics file:

  • measurementTechnique: the sequencing assay, such as whole genome or exome sequencing. Values map to OBI assay terms.
  • sequencingPlatform: the sequencing technology, based on the INSDC platform types. It distinguishes short and long reads, which require different processing.

Optionally, set platform to the instrument model, such as Illumina NovaSeq X.

Assays

Sequencing platforms

Reads

Reads before alignment are a FastqFile or, for basecaller output such as PacBio or Nanopore reads, an UnalignedBamFile. Paired-end files reference each other through pairedWith. RNA-seq and methylation reads are reads like any other: they carry the germline variants of the sequenced regions.

Alignments

Alignments (BamFile, CramFile) specify their coordinate assembly in referenceGenome. UCSC build names map to the matching GRC assembly: hg19 is GRCh37 and hg38 is GRCh38. SAM, the text form of an alignment, is not accepted; convert it to BAM.

Variant calls

Variant calls also give referenceGenome. Germline variants identify a person, so the class says whether a file can contain them: a GermlineVariantFile holds germline calls, joint genotypes, or somatic calls that still include germline variants, such as unfiltered tumor-only calls; a SomaticVariantFile holds somatic calls with germline variants removed, as in the GDC's masked somatic mutation files. The media type tells the format: VCF is text/plain, BCF is application/octet-stream and MAF, a tab-separated table, is text/tab-separated-values. A variant file can reference its source alignment through wasDerivedFrom.

Expression quantifications

Gene or transcript expression quantified from RNA-seq, such as a matrix of counts or TPM per gene and sample, is a GeneExpressionFile. It holds no sequence, so it is not identifying the way the reads it came from are, though expression values can still be linked to a genotype through eQTLs. Formats with no registered media type, such as AnnData, are application/octet-stream.

Indexes

An IndexFile points to the file it indexes with indexOf. Its format follows the indexed file: .bai for a BAM, .crai for a CRAM, .tbi or .csi for a VCF and .csi for a BCF. Indexes are binary.

Media types and compression

Genomics files use text/plain for the text formats and application/octet-stream for the binary ones. BAM, CRAM and BCF compress internally, so they leave compression unset. A compressed FASTQ or VCF declares how it was compressed: bgzf for a file written by bgzip, which a tabix or CSI index requires, and gzip for a plain gzipped file. A VCF delivered with its index is therefore bgzf.

Sensitivity

Sequencing reads and alignments of any assay, and germline variant calls, are identifying: they can identify a person on their own, and W3C DPV classes them as genetic data (pd:Genetic). Removing direct identifiers does not make them de-identified, regardless of sensitivity flags. Germline-filtered somatic calls, expression quantifications and index files are not identifying on their own.

The formats hold sequence data, run metadata and expression values, not dates, postal codes, free text or biometric identifiers about the subject, so none of the sensitivity flags applies to a genomics or index file. They are false whatever the batch says, and a file cannot set them; its sensitivity may hold notes only.
