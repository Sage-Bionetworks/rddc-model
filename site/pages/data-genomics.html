Genomics

Sequencing reads, alignments, variant calls and their indexes. The format is the class, every genomics file states how it was sequenced, and genomic data always identifies a person.

One class per format

FASTQ, BAM, CRAM, VCF and BCF have no registered IANA media type, so encodingFormat cannot tell them apart: it is text/plain for the text formats and application/octet-stream for the binary ones. The pipelines that read them differ by format, so each format has its own class, and the class maps to its EDAM format term. Three abstract classes group them: SequenceReadsFile (FASTQ, unaligned BAM), AlignmentFile (BAM, CRAM) and VariantFile (VCF, BCF). A file always names a concrete class.

Assay and platform

Analysis requires two fields on every reads, alignment and variant file:

  • measurementTechnique: the sequencing assay, such as whole genome or exome sequencing. Values map to OBI assay terms.
  • sequencingPlatform: the sequencing technology, based on the INSDC platform types. It distinguishes short and long reads, which require different processing.

Optionally, set platform to the instrument model, such as Illumina NovaSeq X.

Reads

Reads before alignment are a FastqFile or, for basecaller output such as PacBio or Nanopore reads, an UnalignedBamFile. Paired-end files reference each other through pairedWith.

Alignments and variant calls

Alignments (BamFile, CramFile) and variant calls (VcfFile, BcfFile) specify their coordinate assembly in referenceGenome. UCSC build names map to the matching GRC assembly: hg19 is GRCh37 and hg38 is GRCh38. SAM, the text form of an alignment, is not accepted; convert it to BAM.

A variant file can reference its source alignment through wasDerivedFrom.

Indexes

An IndexFile points to the file it indexes with indexOf. Its format follows the indexed file's class: .bai for a BAM, .crai for a CRAM, .tbi or .csi for a VCF and .csi for a BCF. Indexes are binary.

Media types and compression

Genomics files use text/plain for the text formats and application/octet-stream for the binary ones; the class says which format the file is. BAM, CRAM and BCF compress internally, so they leave compression unset. A compressed FASTQ or VCF declares how it was compressed: bgzf for a file written by bgzip, which a tabix or CSI index requires, and gzip for a plain gzipped file. A VCF delivered with its index is therefore bgzf.

Sensitivity

Genome sequences, alignments and variant calls are identifying: they can identify a person on their own, and W3C DPV classes them as genetic data (pd:Genetic). Removing direct identifiers does not make them de-identified, regardless of sensitivity flags. Index files hold no sequence and are not identifying.

The formats hold sequence data and run metadata, not dates, postal codes, free text or biometric identifiers about the subject, so none of the sensitivity flags applies to a genomics or index file. They are false whatever the batch says, and a file cannot set them; its sensitivity may hold notes only.
