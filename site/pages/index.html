The RDDC data modelThe kinds of data the Rare Disease Data Commons accepts, how each is described, and the metadata sidecar that lists a deposit.

Every file sent to the Rare Disease Data Commons (RDDC) belongs to a data class, such as a FHIR export, an OMOP table, a sequencing read file or a facial photograph. The class defines the file's content, metadata fields, and processing and de-identification requirements.

Each delivery of files comes with a sidecar, _sidecar.json, which lists every file with its class, checksum and subjects. The sidecar is a Croissant dataset with extra fields for clinical data.
