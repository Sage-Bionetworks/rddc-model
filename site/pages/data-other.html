Documentation and other files

Data dictionaries, READMEs and other documentation, plus guidance on GenericFile.

Documentation

A DocumentationFile documents other files: a data dictionary, an acquisition table for images, a codebook or a README. Its modality is metadata, so it is kept with the data rather than processed as data. Its mixed structure permits structured content, such as CSV dictionaries, and unstructured content, such as READMEs.

Use about to reference the documented files. Omit about for a README covering the whole delivery.

Other data

GenericFile is strongly discouraged. A dedicated data class is required; using GenericFile triggers lengthy manual review. Its modality is other.

A generic file is still checked like any other: its sensitivity flags apply, and unknown content is assumed to contain dates, postal codes, free text and biometric identifiers unless declared otherwise.
