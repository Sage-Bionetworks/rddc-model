Source descriptor

The RDDC issues a source descriptor when a source is registered. This small JSON file contains the source details needed to generate and check sidecars offline.

Why it exists

The descriptor supports checks of source details before upload: contributor and source IDs, bucket, prefix pattern and allowed modalities. At receipt, the RDDC checks these against the live source register.

  • The generator uses it to fill in the sidecar header.
  • The validator uses it to run the registry checks locally. Without it, validation still runs and warns that registry checks are deferred to receipt.

region, deliveryRole, descriptionoptionalAWS region; the delivery role identifier (informational; the platform enforces it); a note.

The full definition is in the schema reference, and the JSON Schema is rddc_source_descriptor.schema.json.

Plain JSON, not JSON-LD

The descriptor is a configuration file, not a dataset description. It has no @context and is not a Croissant document. Its values are issued per source and never written into the schema.
